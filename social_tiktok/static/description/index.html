Installation

Get up and running in minutes

Add to addons path

Copy the social_tiktok folder into your custom addons directory and ensure it is listed in addons_path in your Odoo configuration file.

Restart the server

Restart your Odoo server to pick up the new module.

Install from Apps

Go to Apps, search for Social TikTok, and click Install.

Configuration

Three quick steps to connect your TikTok account

Register a TikTok App

Log in to developers.tiktok.com, create a new app, and add Login Kit and Content Posting API. In App settings → Redirect URI add https://<your-odoo-domain>/social_tiktok/callback. Note your Client Key and Client Secret.

Enter credentials in Odoo

Go to Settings → Social Marketing, scroll to the Developer Accounts section, enter your TikTok Client Key and Client Secret, then save.

Connect your TikTok account

Open Social Marketing → Accounts, click the TikTok media card → Add Account, and authorise the app on TikTok. You will be redirected back to Odoo automatically.

Known Limitations

Platform API restrictions to be aware of

🎥
Video-only posts TikTok's Content Posting API does not support text-only or image posts.
💬
No in-app comment management Comment read/write requires the TikTok Research API (separate approval process).
📈
No engagement trends Trend calculation requires historical data not available in the standard API.
⏱️
Access token expiry Tokens expire after 24 hours; refresh tokens last 1 year. Re-authorise the account when prompted.
